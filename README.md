# Redux Toolkit React Cars Application

View Project: [https://redux-toolkit-react-cars-app.netlify.app/](https://redux-toolkit-react-cars-app.netlify.app/)

## Description

An application centered on Redux with Redux Toolkit in React that enables the user to input a list of cars and their prices. Add cars, delete cars, search the list, and see the running total cost calculated at the bottom. A bonus UI feature highlights matching text in boldface when a user is typing in the name of a car to add that is already on the list.
